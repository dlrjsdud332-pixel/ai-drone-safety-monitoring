# 로컬 모델 준비

메인 프로그램은 아래 파일을 이 디렉터리에서 읽는다.

- `yolo11s.pt`: 사람·차량 탐지/추적
- `yolo11n-pose.pt`: 자세 추정
- `ppe_best.pt`: 보호구 탐지
- `fire_smoke_best.pt`: smoke=0, fire=1

새 가중치 파일은 `.gitignore`로 제외한다. 기존 clone에서 추적 중인 `ppe_best.pt`, `yolo11n-pose.pt`, `yolo11n.pt`, `yolo11s.pt` 4개는 그대로 남아 있으며 제외 규칙으로 추적이 해제되지는 않는다. 원 배포처·학습 데이터·배포 조건을 확인한 파일만 별도로 설치해야 한다. PPE와 화재 모델의 재배포 권한은 아직 확인하지 못했다. 임의의 다른 가중치로 대체하거나 모델 파일이 없어도 정상 작동한다고 보고하지 않는다.

라이선스 상태는 `docs/LICENSE_REVIEW.md`를 참고한다. 이번 준비 작업에서 모델 자동 다운로드나 학습을 실행하지 않았다. 기존 소스의 모델 로더 동작까지 다운로드가 없다고 보증하지 않는다.
